# 访谈流程（对话即生成）

目标：学生只要开口聊，本 Skill 就能一路问下来，最后直接给出**属于他自己的**活法清单和页面。学生不需要填表、不需要准备数据文件、不需要会跑命令。

## 铁律

1. **一轮一题**：每条消息只问一个问题，禁止把多题塞进一条消息。
2. **选择题为主**：能做成选项就用选项（A/B/C/D），用户回一个字母就能继续。
3. **能推断就推断**：用户上一句已经透露的信息不再问。学生说"我是大二学前的，想留在福州"，就直接跳过 Q1/Q2 和地域。
4. **不硬凑**：用户说"不知道""随便""没想过"，记 `未指定`，不要替他编，也不要在这一点上再追问第二次。
5. **最多 7 轮**：问完即生成，不要为了信息完整度把学生问烦。
6. **题面照发**：下面的题面是固定的，不要把选项改写成更"高级"的说法。

## 六道题（按需发，已答的跳过）

**Q1 专业**
> 你现在读的是哪个专业？

- 学生只说了学院或方向（"艺术的""信息系的"），用下方专业清单反问他选哪个，不要自己猜定一个。
- 不在 20 个专业清单里：说明"这一届没开这个专业"，列出同学院相邻专业让他选，或按新专业流程现写一份数据（见 SKILL 第五节）。

**Q2 阶段**
> 你现在处在哪个阶段？
> A 大一 / 大二，还在探索　B 大三，快要实习或毕业　C 已经毕业，在找工作　D 其他

**Q3 想要的工作状态（最关键的一题）**
> 如果只能选一个，你更想要什么样的工作状态？
> A 稳定，最好有编制或五险一金
> B 成长快，能一直往上走
> C 收入上限高，愿意承担不确定
> D 自由，能自己安排时间

- 学生的原话要原样写进 `state`，不要只记字母。例："A，稳定，最好能进公办园"。

**Q4 兴趣**
> 下面哪些事你做起来不觉得累？可以多选。
> A 和孩子 / 学生打交道　B 和老人、需要照顾的人打交道　C 和电脑、设备、数据打交道
> D 做内容（拍视频、写文案、做公众号）　E 做设计、手工、画画　F 和人沟通、协调、组织活动

**Q5 优势**
> 你身上更像下面哪几条？可以多选。
> A 有耐心、稳得住　B 动手能力强　C 技术学得快　D 会表达、能讲清楚　E 审美好、会做东西　F 组织能力强

- A~F 之外，学生自己说的具体技能（"会剪视频""钢琴八级""会 Python"）更有价值，原样记进 `strengths`。

**Q6 硬条件（一问三项）**
> 最后三个条件，一句话答就行：想留在哪个城市？毕业先工作还是考虑升学？有没有一定不想干的（比如夜班、销售业绩、长期出差）？

- 这是唯一允许一次问三小项的题，因为对用户是"一句话"的量。
- 学生只答了其中一项，其余记 `未指定`，不要再补问。

**Q7 输出形式（可省）**
> 结果我直接在这里说；需要的话，再给你一个能保存、能发到群里的页面。要页面吗？

- 学生没表态：默认给对话结果 + 页面（页面是本职产出，不用专门征求同意）。
- 学生说"不用页面"：只给对话结果。

## 记录格式

把答案落成 `profile.json`（放中间产物目录），字段与 `scripts/recommend.mjs` 对齐：

```json
{
  "major": "学前教育",
  "level": "专科",
  "grade": "大三",
  "state": "A，稳定，最好能进公办园",
  "interests": ["和孩子打交道", "做内容"],
  "strengths": ["有耐心", "会剪视频", "组织能力强"],
  "region": "福州",
  "further": "maybe",
  "avoid": ["销售业绩", "长期出差"]
}
```

- `level` 专科/本科按学生实际；不清楚就按本校专科填，不追问。
- `further`：升学 → `"yes"`；先就业 → `"no"`；待定或未答 → `"maybe"`。
- 未指定的字段直接省略，不要写"未知""待补充"这类值。

## 访谈结束后

1. 一句话复述画像给学生确认（例："记一下：学前教育大三，想稳定进公办园，喜欢和孩子相处、会剪视频，想在福州，升学待定，不想做销售和长期出差。"）。
2. 学生确认或补充后，进 `references/personalize.md` 的流程生成结果。
3. 不要在学生还没确认画像时就开始输出活法清单。
